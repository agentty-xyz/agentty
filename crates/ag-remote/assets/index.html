Session actions

Merge this session?

Agentty queues a squash merge of the session's changes into its base branch in the project's checkout, as m does in the terminal. A failed merge returns the session to review.

Cancel this session?

Agentty stops the agent and deletes the session's worktree and branch. Changes that are not merged or published are lost.

Forget this device?

This browser stops connecting and needs a new pairing code to come back. Agentty lists the device until you remove it in the remote control popup.
