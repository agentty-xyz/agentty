Session actions

Merge this session?

Agentty queues a squash merge of the session's changes into its base branch in the project's checkout, as m does in the terminal. A failed merge returns the session to review.

Publish this session?

Agentty pushes the session's commits to the session branch on the remote and opens a pull request, with your Git and forge credentials, as p does in the terminal.

Sync this session?

Agentty rebases the session branch onto its base branch, after the running turn if there is one. A conflict starts a turn that resolves it.

Sync the project?

Agentty pulls its branch from its remote, rebases your local commits onto it, and pushes them, with your Git credentials, as s does in the terminal. A conflict starts an agent that resolves it.
