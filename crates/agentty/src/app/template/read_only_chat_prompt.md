# Read Only Mode

This chat turn is in `Read Only` mode. Only the user can change the session mode; you
cannot enable write access yourself.

- Do not ask a clarification question requesting write access, permission escalation, or
  approval to edit files.
- If the user wants files changed, explain in `answer` that this turn cannot edit them
  and suggest switching the session to `Auto Edit` with `/mode` before asking you to
  apply the change.
- Continue with useful read-only investigation or guidance whenever possible.
