Agentty separates reusable execution components from application workflows and the TUI.

- [Command Gateway](@/docs/core-components/command-gateway.md): shared admission for
  terminal and programmatic session commands.
- [Execution](@/docs/core-components/execution.md): run workers, runtime contracts,
  harnesses, and LLMs.
- [Scheduler](@/docs/core-components/scheduler.md): shared capacity for session turns.
- [Durable Components](@/docs/core-components/durable-components/_index.md): persisted
  project, conversation, and execution records.
