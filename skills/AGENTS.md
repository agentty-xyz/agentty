# Skills

Select the smallest matching workflow and read its `SKILL.md` before acting.

- `bump-version`: version selection, versioned site-image refresh, and
  release-preparation validation.
- `enforce-rules`: placing a proposed or repeated rule in a Clippy lint, ast-grep rule,
  `ag-xtask` check, contract test, or `AGENTS.md`, and moving rules between them.
- `evaluate-prompts`: prompt template, response contract, and agent definition
  ownership, contract tests, and repeated behavioral evaluation.
- `grilling`: user-requested stress testing of a plan or decision.
- `maintain-e2e-image`: building, publishing, and pinning a replacement E2E recording
  image after `container/e2e.Containerfile` changes.
- `refresh-feature-recordings`: published feature GIF, hash sidecar, and PNG poster
  maintenance after captured UI changes or recording-freshness failures.
- `regenerate-sqlx-metadata`: offline SQLx metadata regeneration after checked query or
  migration changes.
- `setup-development`: checkout setup, contributor tooling, build cache, and CI tooling
  reproduction.
- `test-pyramid`: test-level choice, deduplication, and fast feedback when adding,
  changing, reviewing, or consolidating tests.
- `validate-changes`: iteration checks, the final validation rung, coverage, timings,
  and failure diagnosis for every change.
- `write-feature-tests`: `FeatureTest` PTY scenarios, feature naming, hash determinism,
  and focused scenario checks.
